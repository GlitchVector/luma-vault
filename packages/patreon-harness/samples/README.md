# Capture samples

Fixed inputs for the capture fixtures. Two images that are obvious at thumbnail
size and obvious in a file dialog:

| file | looks like |
|---|---|
| `01-red.png` | red, short cyan notches down the left |
| `02-blue.png` | blue, long gold bars down the left |

They exist because "attach any two images" is not reproducible. A capture is
only comparable to the one before it if the inputs match, and *which* two
images were used in a capture from three months ago is not a question anybody
can answer — which is exactly how the first `image-2` re-capture stalled.

Solid colours with an asymmetric stripe, generated rather than photographed, so
they are a few hundred bytes each and carry nothing personal. If you replace
them, keep them visually distinct from each other at small sizes — the `teaser`
fixture depends on being able to tell at a glance which one Patreon chose.
